# راه‌اندازی MINOLOGY با موبایل

## وضعیت این نسخه
این یک MVP قابل اجرا برای شروع است: رابط تلگرامی، استخراج خودکار سمت سرور، حساب کاربر، فهرست تسک، ثبت درخواست برداشت و پنل ادمین دارد.
**این نسخه هنوز آماده دریافت پول واقعی یا پرداخت خودکار نیست.** اتصال واریز TON، تأیید تراکنش GRAM، بررسی عضویت کانال، اجرای واقعی برداشت روی بلاکچین، کنترل سن هولد و سیستم ضدتقلب باید پیش از انتشار عمومی تکمیل و تست شوند. در حال حاضر دکمه تسک عمداً بدون تأیید عضویت پاداش نمی‌دهد.

## ساده‌ترین روش با موبایل (GitHub + Render)
1. فایل ZIP را از حالت فشرده خارج کن.
2. در مرورگر موبایل وارد https://github.com شو و یک حساب بساز/وارد شو.
3. یک Repository جدید با نام `minology` بساز و آن را Private یا Public انتخاب کن.
4. در صفحه مخزن، **Add file → Upload files** را بزن و همه فایل‌ها و پوشه‌های داخل ZIP را آپلود و Commit کن. فایل‌ها باید در ریشه مخزن باشند؛ نه داخل یک پوشه اضافی.
5. وارد https://render.com شو و با GitHub ثبت‌نام کن.
6. از داشبورد Render گزینه **New → Blueprint** را بزن و مخزن `minology` را انتخاب کن. Render فایل `render.yaml` را می‌خواند.
7. برای `BOT_TOKEN` مقدار توکن رباتی را که از @BotFather گرفتی وارد کن.
8. برای `ADMIN_PASSWORD` یک رمز طولانی و یکتا بساز. آن را در اختیار کسی نگذار.
9. سرویس را Deploy کن و منتظر بمان تا وضعیت آن Live شود. آدرس HTTPS ساخته‌شده را کپی کن.

## ساخت ربات تلگرام
1. در تلگرام به @BotFather پیام بده و `/newbot` را بفرست.
2. نام نمایشی `MINOLOGY` و یک username آزاد که به `bot` ختم شود انتخاب کن.
3. توکن ربات را فقط در Environment Variable با نام `BOT_TOKEN` در Render قرار بده؛ آن را در چت، کد یا گروه منتشر نکن.
4. در @BotFather از `/mybots` رباتت را انتخاب کن، سپس **Bot Settings → Configure Mini App** یا بخش مربوط به Main App را باز کن و آدرس HTTPS سایت Render را ثبت کن. عنوان منو ممکن است با نسخه BotFather کمی فرق کند.
5. از تنظیمات ربات، Menu Button را هم روی Web App تنظیم کن و همان URL را بده. اگر این گزینه در دسترس نبود، از لینک مستقیم Web App در تنظیمات BotFather استفاده کن.

## پنل مدیریت
آدرس `https://آدرس-سایت-تو/admin` را باز کن و رمز `ADMIN_PASSWORD` را وارد کن. می‌توانی تسک بسازی و درخواست‌های برداشت را تأیید یا رد کنی.

## نکات مهم پیش از انتشار
- Render با دیسک پایدار در پلن پولی اجرا می‌شود؛ فایل SQLite باید روی `/var/data` بماند. پلن‌های رایگان ممکن است دیسک پایدار نداشته باشند و برای داده واقعی مناسب نیستند.
- نرخ استخراج، حداقل برداشت و Hold در تنظیمات دیتابیس پیش‌فرض هستند و باید در نسخه بعدی به تنظیمات کامل پنل تبدیل شوند.
- در این نسخه، مقدار MINO داخل دیتابیس امتیاز داخلی بازی است، نه توکن بلاکچینی و نه دارایی قابل معامله.
- برای واقعی کردن واریز/برداشت باید آدرس قرارداد توکن معتبر، شبکه، تأییدیه‌های بلاکچین، کیف پول خزانه و سیاست‌های امنیتی مشخص شود. کلید خصوصی را هرگز در فرانت‌اند یا GitHub قرار نده.
- برای بررسی عضویت تسک، ربات باید در کانال ادمین باشد و سرور از Telegram Bot API برای `getChatMember` استفاده کند.
- قبل از دریافت هرگونه وجه یا عرضه توکن، بررسی حقوقی/مالیاتی و امنیتی در حوزه محل فعالیت لازم است.

## اجرای محلی برای توسعه
Node.js نسخه 20 یا بالاتر نصب کن، سپس:
`npm install`
`DEV_MODE=true npm start`
بعد آدرس `http://localhost:3000` را باز کن. حالت DEV فقط برای تست است و نباید روی سرور عمومی فعال باشد.
